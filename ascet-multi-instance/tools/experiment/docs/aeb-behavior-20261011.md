# AEB 离线算法行为验收：2026-10-11

在已修复的隔离数据库上，`AEBiBooster_ECU_CSW_BB00001 / Default` 的 8 组算法行为用例通过。工具回归测试通过 16/16。模型继续使用已保存的 `TaskInit`、5 ms 和 20 ms 任务。测试读取实际有效标定，通过外部输入驱动逻辑，没有强写内部触发位、状态机状态或制动输出。

## 用例和观察

| 用例 | 源码导出的预期 | 实测 |
| --- | --- | --- |
| 请求门控、IB、取消及锁定 | 无请求、仲裁 Off 或客户许可撤销时不能激活；有效请求进入 IB；取消后 Off，锁定结束才能重新激活 | 全部通过。IB 状态 21，输出力为负；取消后输出归零；20 秒锁定到期后重新进入 IB |
| BA 加速度门限、维持和压力释放 | 压力已稳定且充足时，实际加速度必须严格小于激活门限；低压退出 | 全部通过。门限 -3 的相等值不能触发，-4 时进入 BA 状态 31；驾驶员压力 46.46875，释放后退出 |
| BA 压力变化率 | 压力变化率可在压力低于静态激活门限时触发 BA，但仍需加速度和使能条件 | 通过。压力约 5.8，低于静态门限 15、高于释放门限 3，进入状态 30 后保持状态 31 |
| IB→BA | IB 中驾驶员压力超过转换门限，切换为 BA | 通过。IB 标志清零，BA 标志置位 |
| 停车保持和使能撤销 | 进入 Hold 后发出保持请求，轴控制延长时间结束后关闭；保持使能撤销后退出 | 通过。状态 41、`CSMHoldReq_Hold`；延长时间后关闭轴控制；退出后请求为 None |
| 保持超时 | 保持计时严格大于最大保持时间后进入释放状态 | 通过。最大值 1.7 秒，计时 1.705 秒时观测到状态 50 和 `CSMHoldReq_Release`；未接入外部保持确认，随后释放完成 |
| 油门双踩退出 IB | 第一次踩下→释放→第二次踩下，计数达到 2，产生驾驶员退出请求 | 通过。按事件捕获踏板状态 3、计数 2、退出标志 true 和 IB 关闭；之后退出标志复位 |
| 禁用油门退出 | 退出功能禁用时，双踩不得退出 IB | 通过。三段踏板输入 25→0→25，IB 持续有效，退出标志 false |

IB 用例中目标加速度 -3、反馈加速度 0，激活后输出力从 -1160 发展到 -3912。BA 加速度门控用例中反馈 -4、目标 -3，输出力为 0；该用例证明 BA 状态路径，不声称该工况会增加制动力。其他制动力数值仅作为测量证据，未以同一实现代码复制计算充当独立数值 oracle。

## 预期依据与采样

预期来自本地 ASCET 生成代码：`AEB_ReleaseM.c`、`AEB_Trigger_IB_From_OffM.c`、`AEB_Trigger_BA_From_OffM.c`、`AEB_Trigger_Off_From_IBM.c`、`AEB_Trigger_Off_From_BAM.c`、`AEB_Trigger_BA_From_IBM.c`、`AEB_State_MachineM.c`、`AEB_AutomaticBraking_SMM.c` 和 `AEB_DriverAcceleratesM.c`。调用关系经 `AEB5msM.c`、`AEB_light_classM.c`、`AEB_CoreM.c` 和预处理模块核对。私有模型源码、AMD 和数据库仅保留在本地。

测试以 `exp_write` 写入外部信号，在暂停状态读取物理量。每段记录实际仿真时间；持续时间步进可能在事件边界结束，报告不会以请求时长替代实际时长。保持释放和双踩退出通过 `exp_step(mode=condition)` 按事件捕获瞬时状态。报告包含输入回读、观测点、断言、清理结果及操作日志；这是离散检查点，不是完整日志波形。

## 有效标定差异和验证范围

实际执行的 `AEB_DriverAccelerates.C_AEB_DeadTimeAccelerateReq` 为 **0 秒**，公共 `P_AEB_DeadTimeAccelerateReq` 为 **0.4 秒**。即使执行 `update_dependent`，两者仍不相等。本次测试保持模型算法不变，按实际有效参数运行，证明双踩功能和禁用门控；**未证明公共 0.4 秒死区参数正确传递或生效**。该差异需要单独核对模型参数绑定后再验证。

验证处于 PC 离线算法层：车速、实际加速度、驾驶员制动力和停车反馈由用例输入提供，没有车辆、轮胎、液压系统的闭环被控对象。没有接入 HIL、真实 ECU 或 iBooster 硬件，没有验证制动距离和整车安全性能。保持超时测试未接入 CSM 保持确认路径。其他未列出的工况、标定和故障组合不在此次通过结论内。
