agent-provided executable code. It independently requires:

- The exact prepared candidate, native CURRENT bindings, private patch and clone
  correspondence are unchanged.

  its Class method/formal, exact parent collection and incident-edge constraints

## Why This Is Required

The accepted temporary publication study stores a private patched diagram and then
restores its retained CURRENT. Complete persisted-source equality is proven, but
does not prove preservation of the active diagram's existing object identities.
An ordinary edit's later inverse can still hold references to those real objects.

Recovered source specifically shows `SGMethodInterfacePortGO>>removeInterfaceGO:`
only removing from `interfaceGOs`, and `addInterfaceGO:` only appending. Therefore
recovery must use the recorded original order and exact retained objects; append
is not a general ordered inverse. See
[removal](../unpacked/smalltalk-source/ASDBase.ic/SGMethodInterfacePortGO.st:150) and
[append](../unpacked/smalltalk-source/ASDBase.ic/SGMethodInterfacePortGO.st:160).

`EtasAPIDiagram>>endModifications` stores the actual top hierarchy, marks the source
modified, calls `item recreateLogicModel`, then commits. The source chain alone
does not prove that every existing runtime reference survives these effects;
actual post-store identity and later ordinary inverse checks are required. See
[endModifications](../unpacked/smalltalk-source/ASDBase.ic/EtasAPIDiagram.st:1316).
These are recovered-source observations, not additional live acceptance.

The next live executor must remove only the bound current inputs and restore only
the planned coordinate fields, then store that same current diagram. Serialization
cache changes in the private patch are not commands to copy every private field
onto the current graph. Full actual diff/source checks remain necessary after the
real store, including any native side effects.
