  and created formal. Caller targets require exact Class OID, method alias, formal

## Allocator Policy

The audited chain is `EtasAPIDiagram>>endModifications` ->
`SGSpecificationWithSource>>saveGraphics:pageFormat:` ->
`SGTopGraphicsBlockDB>>store:pageFormat:`. Store initializes
`SGHierarchyWrapperGO>>buildNewIdentifiersMaximumGraphicsIdentifier:` with the
current source's high-water and stores the builder's resulting actual index.
`highestUsedGraphicalIdentifier` retains that value; it only recalculates when nil.

Consequently the local candidate preserves the current high-water, including IDs
of removed pins. Both the native planner and independent Python merge enforce a
monotonic original/applied/current integer history and report this explicit policy.
They compare complete sources without dropping the allocator field or inserting
candidate metadata into runtime output. Exact whole-owner restoration remains a
separate unchanged executor. Nil-to-integer history is conservatively unsupported.
