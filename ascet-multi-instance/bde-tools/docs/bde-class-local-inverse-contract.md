## Available preview

`bd_revert(change_id, request_id, preview=true)` reads the actual immutable WAL
before/after and reuses its existing current-owner observation. It does not
perform a second semantic read for field analysis. Known restoration holds,
expired endpoints and released changes leave `patch_analysis="not_checked"`.

The returned `patch_analysis` contains:

- `original_after_matches`: exact JSON values/types, not Python numeric equality.
- `collected_graph_compatible`: collected owner graphs permit the proposed value
  inverse; this is not complete native/configuration/interface compatibility.
- `identity_guards`: owner/scope identity or coverage changes.
- `resources`: owner OID, exact diagram, conflicts, preserved changes, field
  expectations/restoration values and compatible current-to-merged row deltas.
- `observation_fields_requiring_native_recheck`: changed signature/configuration/
  public observation boundaries, separately from graph field conflicts.
- `write_authorized=false`, `native_merge_executor_available=false`.

Missing and null are distinct. Ordered pin lists and routes are atomic values.
A changed native generation refuses; same row identity is not inferred from a
display name. A conflicting graph resource has no candidate merged row patch.
Changed observations always refuse the existing whole-owner restore with
`STRICT_INVERSE_BASELINE_REQUIRED`, even when their collected graph values could
be merged. Preview does not reserve an edit request or retain new recovery objects.

## Required native executor

The existing `bde_class_materialize.st` restores its entire retained original
diagram. Relaxing its equality guard would overwrite independent changes.
A separate audited executor is required before enabling local inverse:

1. Resolve current graph objects and retained deleted originals in the same native
   epoch. Verify original aliases, owner membership, detached contents, registry
   generation, ordering and stored graphics source immediately before setters.
2. Recheck touched field expectations plus signature/caller/resource closure and
   effective configuration/dependencies. Collect native current identities for
   independent objects; the value planner cannot prove their preservation.
3. Merge original deleted formals/pins/nodes/edges into the current graph and undo
   only recorded touched fields. Preserve independent current objects/fields and
   validate exact connector order, new incident edges and configuration bindings.
4. Prepare durable per-owner WAL and current-state recovery material before the
   first setter. Journal partial/unknown batches and actual after observations.
   Do not replace a current registry with the complete old registry.
5. Verify against independent public/native observations, including original
   removed identities and unchanged independent fields. Exercise setter/store/
   transport faults, shared owners, reload and source changes before accepting.

No arbitrary agent-supplied Smalltalk or reconstructed same-name formal is an
implementation of this contract. Original display01 recovery remains separately
required; successful synthetic/offline merges never clear its restoration hold.
