## Behavior

Before, applied, and current observations are compared independently in Python
and in a fixed compiled Smalltalk helper. An inverse restores only deleted rows
into CURRENT. Compatible later values and members survive; complete lookup counts
are adjusted by the original deletion delta. Missing dependencies, occupied
inputs, reappeared references, changed identity/metadata, endpoint geometry changes,
detached-original changes, stale preflights, and ambiguous collection gaps refuse.

Native parent order remains a separate exact-reference three-way check. When a
new object and an original deleted run occupy the same gap, their precise order
is unknown: `RESTORE_GAP_AMBIGUOUS` refuses the inverse before setters. An addition
in a different gap can remain while the original deletion is reverted.

Smalltalk Dictionary equality is insufficient for copied graph values. The
helper recursively compares typed dictionaries and ordered collections; Float
values compare Cebra bytes. This avoids confusing value equality with identity.
The adapter binds fixed helpers; no arbitrary source or selector tool is exposed.

`bd_revert(preview=true)` cross-checks the Python expected graph against native
preflight. The durable inverse preparation saves CURRENT, the merged expected
graph, analysis, raw CURRENT, and signatures before dispatch. Actual results must
match the merged graph. Lost terminal replies require the same durable/native
expectation. Released-record reconciliation recomputes the durable three-way plan
without reconnecting. Missing or altered expectations refuse reconciliation.

Large observations stay in the WAL; agent receipts contain changed refs, counts,
hashes, and conflicts. A later compensation is a separate journaled edit; it is
not presented as the inverse of the secondary edit.
