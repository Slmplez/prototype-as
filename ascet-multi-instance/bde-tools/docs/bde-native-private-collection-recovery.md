## Native Structure And Mutations

The fixed experimental preparation selects existing memo-owned collections from
a complete native graphical clone. No replacement synthetic collection is used:

| Collection | Actual Private Structure | Fixed Private Setup |
|---|---|---|
| Dictionary | RBConnectionPointBranch connections | Replace one registered value with another retained OrderedCollection |
| Set | RBConnectionPointBranch branchingPoints | Add two distinct retained Points to an existing empty Set |
| Array | A connected edge's connectionPoints | Swap the two retained endpoint references in the existing Array |

These changes exercise physical recovery of native containers. Dictionary value
replacement and direct Set/Array edits are research mutations, not a proof of a
valid production reconnect, route edit or model operation. The before/original
projection is checked with independent public getters on the original owners.

Native capture copies Dictionary associations by rebuilding keys and values while
retaining the exact referenced objects. Prediction and conflict probe snapshots
use the same copy rule. This prevents mutable associations from changing retained
images. Dictionary/Set wire images use canonical iteration order; Array and
OrderedCollection retain their actual order. The offline auditor compares unordered
images by their members/key-value bindings and compares instruction order, target
identity, counters and unknown-state metadata exactly.

Every required new-collection case fails before a physical step or after its return,
kills only its dedicated C# bridge, retrieves the same retained wire/material,
observes without replay, introduces an independent x edit and a distinct third
collection image, verifies conflict refusal, resets that probe exactly, classifies
the original pending step read-only and resumes at the correct next index.
Release requires complete CURRENT equality after the explicit independent reset.

The new matrix tests first and last steps. Array and Set schedules have two steps.
Some Dictionary schedules have more than two: their middle failure positions are
not tested by this matrix. The original OrderedCollection regression retains all
three positions. Failures inside one primitive, naturally throwing setters,
coordinator/ASCET death and cross-restart native archives remain unverified.
