## Current Implementation

`current_class_execution.st` consumes retained publication entries and the exact
`current_class_identity_plan.st` bindings. Agent requests cannot supply native
objects, selectors or Smalltalk source. The executor constructs an ordered
primitive schedule and its inverse before any model dispatch.

- Existing pin layout setters retain both the exact connector and before Point.
  Newly allocated desired Points are included in native observation.
- Removal slots are computed against a simulated sequential collection prefix.
  Removing multiple targets from one collection does not reuse shifted original
  indices. Each removal verifies the current slot's object identity.
- Pin removal uses the audited `removeInterfaceGO:` path. Node removal and manager
  clearing remain separate primitives. Insertion inverses restore original order.
- Original/latest snapshots and operation rows have independently copied seals.
  Each primitive requires the exact observed native prefix, then compares actual
  diff with its declared effect. Unexpected effects retain an unclassified action.
- A started action cannot be replayed. Preparation is default OFF and requires
  the complete publication and CURRENT identity research profiles.

The unaccepted write commands are `apply/N`, `publish_store`,
`undo_publish_store/N`, `undo_apply/N`, `restore_store`,
`undo_restore_store/N`, and `finish_restore`. Stores target the retained actual
CURRENT diagram. The template drafts per-primitive inverse actions for observed
store effects, and traverses the resulting graph to check existing member identity.
These paths are compiled, but have not been executed or accepted online.

The only integrated route is `--current-execution-preflight`, guarded by
`ASCET_BD_CLASS_CURRENT_EXECUTION_PREFLIGHT=1`. It prepares all owners, records
value-only receipts in a separate checksum-chained preflight WAL, and executes
zero CURRENT model setters. The existing publication experiment continues to
publish private diagrams and restore CURRENT through its previously tested path.

## Native Capture

`current_class_native_capture.st` observes original native graph objects and
planned new Points. Every capture walks audited mutable fields and six collection
types. Newly encountered objects join the retained observation roster, including
objects subsequently removed from a collection. This detects later changes to
new nested objects and prevents removal from silently reducing diff coverage.

Array and OrderedCollection comparisons use exact ordered identity. Dictionary
and IdentityDictionary compare keys and value identities. Set and IdentitySet
compare membership identities. DB/model and presentation boundaries match the
existing graph clone contract; full public/source/configuration oracles remain
required outside those boundaries. Unsupported mutable/indexed objects and
in-place String/ByteArray changes refuse execution.

Internal snapshots retain native references. Agent-facing reports contain values,
classes, stable graph keys and field information, not executable native references.
