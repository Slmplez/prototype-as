# Class Publication Completion-Loss Recovery

The fixed default-off publication study can classify an interrupted native action
against its durable WAL prefix and restore only the remaining pre-publication
CURRENT. This remains isolated research. Production Class local inverse through
`bd_revert`, native setter failures, actual Cebra disconnects and ASCET restart
recovery are not accepted by these experiments.

## Recovery Protocol

1. Persist the complete CURRENT observation, database/process identity and prepared
   owner roster before any signature or caller-store dispatch.
2. Persist each exact `step_started` before the native action. A missing completion
   is unknown, even when an experimental diagnostic contains the native reply.
   The recovery planner does not use that diagnostic reply to authorize recovery.
3. Read the retained native state without setters. Independently compare all
   complete owner sources, signatures, counters, identities and owner states with
   the confirmed WAL prefix and the possible completed active step. Require one
   uniquely compatible outcome.
4. Reclassify before recovery, persist a separate recovery WAL, and execute only
   its remaining actions. Unpublished owners require metadata reconciliation and
   zero stores; already restored owners are skipped. Never replay the original
   unknown dispatch.
5. Verify the complete original CURRENT through independent public/native reads.
   Only then release its publication record and exact quarantine. Separate ordinary
   and strict Class inverses restore the original experiment baseline, followed by
   a read-only absence audit. Original failed files remain unchanged.

## Transitional Signature Reading

The mixed fixture's seventh dispatch restores the arguments but has not yet called
`method modified` and `autoCommitDatabase`. Actual argument identities, return
identity and configuration match the retained CURRENT, but `getModelType` reports
`BDE_CLASS_PROBE_ERROR: Formal model type unavailable`.

`bde_class_native_signature_probe.st` reads the complete primitive signature from
the exact native formals. Its name/type path uses `elementName`, `sgClass`,
`hasBasicType`, `basicType` and `label`, already audited for retained partial
creation recovery. Method/formal aliases, owner, order, direction, return, diagram,
Class identity and complete reference rows are all retained.

The publication manager compares the native and public full encodings whenever
the public getter succeeds. Only the exact error above permits the native
projection; arbitrary getter errors and unsupported enum/complex types refuse.
Python independently verifies decoded native signatures against the durable full
CURRENT and the exact appended-formal inverse. Native identity and configuration
checks remain mandatory. A valid value comparison cannot replace object identity.
The final restored public getters must still succeed and equal the original full
baseline; the transient native observation is not a public-API acceptance result.

## Remaining Work

An action stuck inside a native setter, commit or store cannot currently be
uniquely classified by this protocol and must refuse recovery. Native archive
restoration across epochs is not implemented. Production publication must preserve
existing object lineage and remain compatible with other patches' later inverses
before the strict `bd_revert` guard can change. Class output/enum/complex, ordinary
families, complete native UI, dependent/shared FLOW/A2A/XPass, isolated AEB_Core,
one-second write performance, verified package and original AEB_1 restoration
remain required. State machines and Code Mode remain deferred.
