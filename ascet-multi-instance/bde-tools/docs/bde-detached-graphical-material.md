never from objects observed after a later change. Roots are the genuine removed
objects and original endpoint-registration collections. Exact parent/top-scope

mutable values and collection contents use the complete raw comparison contract.

capture, before publishing the applied state. Preview and actual inverse check it
after the structural getter. Actual inverse checks again with CURRENT/signature
and endpoint/order guards before `mutationStarted` or a model setter. A preview
cannot bless already altered detached material by capturing it as a new baseline.

check. Host `current == after` and native scoped observation equality still gate
the inverse, so compatible independent model edits are **not yet accepted**.
